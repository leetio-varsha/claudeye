# Claudeye — Идея

Claudeye — это память и аналитика для Claude Code. Система записывает всё что происходит в сессиях, находит релевантный контекст из прошлого и подставляет его автоматически. Поверх памяти работает аналитика: friction scores, hotspots, паттерны ошибок. Advisor анализирует не только работу с Claude Code, а всю рабочую деятельность — задачи, PR, коммуникации — и рекомендует что автоматизировать. Один агент выполняет конкретный use-case через контекст Claudeye, а feedback loop позволяет системе учиться на своих действиях. Knowledge Graph связывает сущности (файлы, баги, решения), Decision Memory сохраняет не только что произошло, а почему. Конечная точка — Personal AI OS: система которая знает все проекты, паттерны и стиль разработчика.

## Team Level

Те же принципы масштабируются на команду. Каждый дев работает локально — raw данные не покидают машину. Наверх уходят только агрегированные метрики: friction, модели, плагины, паттерны. Тех лид видит где команда буксует, какие инструменты реально работают, что можно стандартизировать. Иерархический CLAUDE.md (global → team → project → personal) унифицирует практики без потери личного контроля. Shared Knowledge Base позволяет команде учиться на опыте друг друга: дев решил проблему — расшарил решение, другой нашёл его через поиск. Онбординг за одну команду: `npx claudeye join <token>`. Принцип: privacy-first, insight-driven, не слежка.

## Стратегия

ядро → польза → один агент → обучение → масштаб

Сначала личный инструмент, потом команды, потом платформа. Open-source ядро, монетизация на аналитике и advisor-слое.
