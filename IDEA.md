# Claudeye — Идея

Claudeye — это память и аналитика для Claude Code. Система записывает всё что происходит в сессиях, находит релевантный контекст из прошлого и подставляет его автоматически. Поверх памяти работает аналитика: friction scores, hotspots, паттерны ошибок. Advisor анализирует не только работу с Claude Code, а всю рабочую деятельность — задачи, PR, коммуникации — и рекомендует что автоматизировать. Один агент выполняет конкретный use-case через контекст Claudeye, а feedback loop позволяет системе учиться на своих действиях. Knowledge Graph связывает сущности (файлы, баги, решения), Decision Memory сохраняет не только что произошло, а почему. Конечная точка — Personal AI OS: система которая знает все проекты, паттерны и стиль разработчика. Стратегия: ядро → польза → один агент → обучение → масштаб. Сначала личный инструмент, потом команды, потом платформа.
